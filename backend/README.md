# Backend

The backend is planned but not required for the current standalone v0.3 application.

Target responsibilities:

- server-side LLM calls and tool routing;
- private project persistence;
- authenticated user workspaces;
- GDSII/OASIS parsing and export;
- long-running optimization jobs;
- optional interfaces to external simulation packages;
- audit logs for AI-proposed design changes.

Recommended stack: Python + FastAPI.
