# Frontend

The current frontend is the standalone root `index.html`.

The planned production frontend will preserve the existing scientific-CAD layout while separating the application into reusable components:

- design parameter inspector;
- 2D device/GDS viewport;
- layer explorer;
- geometry table;
- DRC and violations panel;
- NanoPattern Copilot;
- export and project controls.

A later migration can use React/Next.js once the product behavior and geometry APIs stabilize.
