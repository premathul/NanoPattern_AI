# Geometry Engine

This module will become the deterministic geometry kernel for NanoPattern AI.

Planned responsibilities include:

- parametric nanostructure generation;
- polygons, paths, cells, layers, and hierarchy;
- center-to-center and edge-to-edge distances;
- symmetry and taper analysis;
- GDSII/OASIS import and export;
- geometry transformations;
- layout normalization and validation.

Candidate libraries: KLayout, gdstk, Shapely, NumPy.
